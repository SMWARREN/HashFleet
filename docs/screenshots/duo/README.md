# iPhone Duo App Store Screenshots

This directory contains App Store Connect screenshot assets for the foldable Apple iPhone Duo device category.

## Specifications

| Asset | Target Screen | Canvas Size (Points) | Native Output Resolution (Pixels) | Size Class |
|---|---|---|---|---|
| `iphone-duo-outer-dashboard.png` | Folded Outer Display | 466 × 678 pt | 1398 × 2034 px (@3x) | Compact |
| `iphone-duo-inner-dashboard.png` | Unfolded Inner Display | 669 × 951 pt | 2007 × 2853 px (@3x) | Regular |
| `iphone-duo-inner-detail.png` | Unfolded Inner Display (Detail) | 669 × 951 pt | 2007 × 2853 px (@3x) | Regular |

## Layout Behavior

- **Outer Display**: Single-column compact card presentation designed for glanceable reading on the cover glass.
- **Inner Display**: Symmetrically splits the fleet dashboard cards across two columns around the center hinge/crease line, leveraging the regular size class (`width >= 560 && width < 960`).
