# HashFleetCore contract

Swift 6, Foundation only, iOS 17/macOS 14+. No network operation runs automatically.

- `MinerDevice: Identifiable, Codable, Hashable, Sendable`: mutable `id: UUID`, `name: String`, `address: String`; `init(id: UUID = UUID(), name: String, address: String)`; `validatedURL() throws -> URL` accepts host/IP/mDNS with optional HTTP(S) scheme and port, no credentials/path/query/fragment.
- `JSONValue: Codable, Hashable, Sendable`: `.object([String: JSONValue])`, `.array([JSONValue])`, `.string(String)`, `.number(Double)`, `.integer(Int64)`, `.unsignedInteger(UInt64)`, `.bool(Bool)`, `.null`. Accessors `stringValue`, `doubleValue`, `intValue`, `boolValue`, `objectValue`, `arrayValue`. `prettyPrinted() throws -> String`.
- `MinerInfo: Codable, Hashable, Sendable`: `init(raw: [String: JSONValue])`; public `raw: [String: JSONValue]`; decoded/encoded directly as firmware's flat object. Tolerant computed nonoptional facade defaults missing numeric fields to 0 and strings to empty. Double: `hashRate`, `power`, `temp`, `vrTemp`, `fanSpeed`, `fanRpm`, `voltage`, `frequency`, `coreVoltage`, `wifiRSSI`. Int: `sharesAccepted`, `sharesRejected`, `uptimeSeconds`. String: `hostname`, `version`, `asicModel`, `bestDiff`, `poolURL`. `value(for:) -> JSONValue?` preserves distinction between absent and zero. Extras remain in `raw`.
- `MinerEndpoint: Hashable, Sendable, Identifiable`: enum cases `.info`, `.asic`, `.statistics`, `.dashboardStatistics`, `.scoreboard`, `.wifiScan`, `.logs`, `.identify`, `.restart`, `.pause`, `.resume`, `.dismissBlockFound`, `.settings`, `.boot`, `.updatePool(Int)`, `.deletePool(Int)`, `.otaFirmware`, `.otaWWW`, `.theme`, `.updateTheme`, `.logWebSocket`, `.liveWebSocket`, `.recovery`, `.options`. Pool indices validated at request time, 0...7. Exposes `id: String`, `title: String`, `path: String`, `method: String`, `isWebSocket: Bool`, `isDestructive: Bool`, `contentType: String?`, `timeout: TimeInterval`. Static `catalog: [MinerEndpoint]` includes all operations with pool slot 0 as sample. `.allCases` aliases catalog. Themes confirmed GET/POST `/api/theme`. Catalog contains 23 current operations plus `.dashboardStatistics`, marked `isLegacy`, absent from current master. `.options` uses fixed `/api/system/info` with OPTIONS.
- `MinerAPIClient: Sendable`: `init(device: MinerDevice, session: URLSession = .shared)` (nonthrowing, validates before requests); `info() async throws -> MinerInfo`; `execute(_ endpoint: MinerEndpoint, body: Data? = nil, query: [URLQueryItem] = []) async throws -> Data`; `executeJSON(_ endpoint: MinerEndpoint, body: JSONValue? = nil, query: [URLQueryItem] = []) async throws -> JSONValue`; `request(for:body:query:) throws -> URLRequest` for local inspection/tests.
- WebSocket: `webSocketStream(_ endpoint: MinerEndpoint = .logWebSocket) throws -> AsyncThrowingStream<MinerWebSocketMessage, Error>`, frames `.text(String)` / `.data(Data)`. Consumer task cancellation cancels socket. Buffer is 512 pending frames with explicit `webSocketBufferOverflow` failure on overflow, not silent drops. Live frames are full-initial-state then diff envelopes (`event: update`, `data: ...`). `.liveWebSocket` supports firmware live pushes. Convenience `logStream()` and `liveStream()` return same frame stream.
- `MinerAPIError: Error, LocalizedError, Sendable`: invalidAddress(String), invalidPoolIndex(Int), webSocketRequired, notWebSocket, invalidResponse, binaryBodyRequired, webSocketBufferOverflow, http(statusCode: Int, message: String, body: Data). HTTP error body remains available verbatim. OTA bodies sent unwrapped as application/octet-stream, timeout 300 s; regular requests 15 s, Wi-Fi scan 30 s.

Caller owns confirmation UX for all mutations, polling scheduling, persistence, ATS/local-network app declarations, and supplying binary OTA data. No real miners contacted during implementation.

`request(for:)` can inspect WS/WSS URLs locally. `execute` rejects WebSocket endpoints. Empty/nil OTA bodies and `executeJSON` OTA calls throw `binaryBodyRequired`. HTTP redirects are refused, requests skip cookies/cache and add no Origin/Authorization. `executeJSON` maps an empty successful body to `.null`. Source files pass Swift 6 strict concurrency for macOS 14 and iOS 17 simulator.
